# HTML Fundamentals

This repository is dedicated to learning and understanding the fundamentals of **HTML (HyperText Markup Language)**, covering the core concepts and essential elements used to structure web pages.

It contains notes, explanations, and practical examples for each chapter to help understand how HTML works and how its different elements are used in web development.

Topics covered include:

- **HTML Structure:** Understanding the basic structure of an HTML document.
- **HTML Elements & Tags:** Learning about different HTML tags and their purposes.
- **HTML Attributes:** Understanding how attributes provide additional information to HTML elements.
- **Headings & Paragraphs:** Working with text and content formatting.
- **Links & Images:** Adding hyperlinks and images to web pages.
- **Lists & Tables:** Organising information using ordered lists, unordered lists, and tables.
- **HTML Forms:** Creating forms using input fields, labels, buttons, and other form elements.
- **Semantic HTML:** Understanding semantic elements and how they improve webpage structure.

The goal of this repository is to build a strong foundation in HTML through simple explanations and practical examples from each chapter.
